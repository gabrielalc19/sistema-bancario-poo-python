# Sistema Bancário em POO com Python

Este projeto é uma simulação de um sistema bancário simples desenvolvido com Programação Orientada a Objetos (POO) em Python. Ele foi criado como parte do desafio prático da [DIO - Digital Innovation One](https://www.dio.me/), na trilha "Formação Python Developer - Suzano".

# Funcionalidades

- Criar contas bancárias para diferentes titulares
- Realizar depósitos e saques com validação de saldo
- Listar o saldo atual de cada conta
- Cadastrar múltiplas contas e exibir todas no final

# Tecnologias

- Python 3.x
- Programação Orientada a Objetos (POO)
